# Panel Fleet

A Home Assistant add-on that shows every Kiosk Satellite and ha-paneld wall panel on the network at a glance: whether it is online, whether its app is current, what it is showing and a link to its own admin page.

It is a high-level view only. Settings, updates and everything else stay in each panel's own admin page.

## Install

1. In Home Assistant, go to **Settings > Add-ons > Add-on Store**, open the menu and choose **Repositories**.
2. Add `https://github.com/davidcoulson/ha-panel-fleet`.
3. Install **Panel Fleet**, start it and turn on **Show in sidebar**.

See [DOCS.md](panel_fleet/DOCS.md) for what it shows and where the information comes from.
